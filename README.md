# nenithale.com

The website for nenithale.com, served by GitHub Pages. Pages are Markdown; `_layouts/default.html` is the one page template.

- `shuffleplus/privacy.md`: the Shuffle+ privacy policy, linked from the app and from App Store Connect.
- `shuffleplus/support.md`: the Shuffle+ support page, linked from the app and from App Store Connect.

The app links to these URLs, so do not move or rename the two pages.
